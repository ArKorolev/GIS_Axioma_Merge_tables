# GIS_Axioma_Merge_tables
Мастер объединения и конвертации ГИС-данных для ГИС Аксиома


Модуль предоставляет комплексное решение для объединения пространственных данных в различных форматах ГИС.


Основные возможности:  
    - Объединение ГИС-данных в единый файл (слой, таблицу)  
    - Поддерживаемые форматы ГИС-данных (TAB, MIF/MID, SHP, GeoJSON, GPKG, KML)  
    - Работа как с файлами на диске, так и с открытыми таблицами в ГИС Аксиома  
    - Автоматическое определение и проверка систем координат  
    - Контроль совместимости структур объединяемых данных  


Установка производится путем добавления *.axp-файла в раздел "дополнительные модули".  
Модуль появится в ленте во вкладке "Дополнительно" в разделе "Команды".
